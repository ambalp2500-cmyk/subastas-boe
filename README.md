# Subastas BOE · Barcelona y Girona

Aplicación web para consultar en el móvil las subastas del Portal de Subastas del BOE:

- Inmuebles en la Cerdanya, Barcelona, Martorell, Sitges y Vilanova i la Geltrú.
- Bienes muebles (vehículos, embarcaciones y otros) de las provincias de Barcelona y Girona.

Los datos proceden del Portal de Subastas del BOE (subastas.boe.es). Confirma siempre la información en el anuncio oficial.
